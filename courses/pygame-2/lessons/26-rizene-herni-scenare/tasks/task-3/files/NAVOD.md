# Testovatelný model Honu na dronech

Tato pracovní složka obsahuje skutečný model z21–25 a váš reseni.py.
Spusťte python reseni.py ve stejné .venv s pygame-ce==2.5.8.
Modelové scénáře a unittest nepotřebují herní okno, zvuk ani fyzické vstupy.
Pomocné over_projekt.py spustí připravené testy v adresáři testy;
vlastní testy této lekce jsou přímo ve vašem reseni.py.
