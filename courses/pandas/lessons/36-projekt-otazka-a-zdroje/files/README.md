# Analytická dílna: cvičná měření teplot

Otázka: jaké průměry mají známé stanice a co jsme museli vyřadit nebo nedokázali spárovat?
Všechna data jsou vlastní a smyšlená. Řádek je jedno pozorování, ne celý den ani jedna osoba.
Dvě stejně vypadající pozorování jsou v tomto zdroji dvě platná měření. Nemáme pravidlo pro jejich automatické odstranění.
Časy a výběr stanic nejsou reprezentativní vzorek: nevyvozujeme dlouhodobé počasí ani příčinu rozdílů.

Soubor mereni.csv je původní textový zdroj; mista.csv katalog s jedinečným kod.
Čtěte UTF-8 se středníkem, dtype="str" a keep_default_na=False. Doslovný kód NA je platný.
Zdroje nepřepisujte. Přiložený predchozi.py obsahuje ověřené kroky minulých lekcí, aby šla každá lekce spustit samostatně.
